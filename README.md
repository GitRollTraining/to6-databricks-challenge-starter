# Databricks Challenge: prepare a case-selection dataset

This is Challenge 3, the first Databricks Challenge.

Help the next modelling team start with usable data: reject a faulty delivery, check its
replacement, build a feature table and split it into training, validation and test years.
You will work in Databricks and submit the code and evidence to your own private GitHub repository.

1. Follow [START_HERE.md](START_HERE.md) to connect your repository and try the ungraded practice.
2. Complete the four outcomes in [CHALLENGE.md](CHALLENGE.md), starting from `notebook.py`.
3. Fill in [SUBMISSION.md](SUBMISSION.md), commit your notebook and small exports in `outputs/`,
   and verify them on GitHub. Submit your repository URL, `main` and final commit SHA in Classroom.

The Classroom assignment gives the opening time, deadline and reviewer access instructions.
Keep this README as your navigation page. The task can be completed entirely in the browser;
Genie Code is optional. [Other optional tools](OPTIONAL_TOOLS.md) are available if you already use them.
